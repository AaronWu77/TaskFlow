# TaskFlow App Store 化后续计划

## 功能目的

### 问题

TaskFlow 已具备可用的任务流、日历、账号和离线同步能力，但 v1 当前仍有三类产品化问题：

1. 产品模型偏重：进度百分比、完整表单、重复设置同时暴露，削弱了“只关注下一件事”的核心定位。
2. 界面仍主要由 Web 卡片和居中弹窗组成，导航、主要操作、Sheet、日期选择等没有充分利用 iOS 原生交互。
3. iOS 发布配置和公开隐私政策尚未收口，当前最低系统版本、设备范围和商店合规材料不适合直接提交。

### 目标

1. 将 v1 收敛为“快速记录 → 聚焦当前任务 → 完成或移到队尾”的轻量闭环。
2. 保留任务卡作为品牌化内容层，使用空间、字号和材质建立层级，减少边框与卡片套卡片。
3. 采用“React 内容与业务层 + SwiftUI 原生控制层”的渐进式混合架构，不完全重写现有应用。
4. 将 iOS 发布范围固定为 iPhone 竖屏，并建立可重复构建、真机测试和 App Store 提交所需配置。
5. 提供公开、可长期访问且与实际数据处理一致的隐私政策。

### 范围边界

1. v1 不提供任务进度百分比，不新增项目、子任务、团队协作或 AI 功能。
2. v1 的“稍后处理”只表示“移到当前任务队列末尾”，不增加“今晚、明天、下周、自定义时间”的第二套延后模型。
3. React 继续负责任务状态、缓存、同步、冲突处理和 API；SwiftUI/UIKit 只负责 iOS 控制层与系统组件。
4. Web 版本保留 React 控制层作为回退；原生控制层只在 Capacitor iOS 环境启用。
5. v1 最低支持版本暂定 iOS 17.0，使用最新要求的 iOS SDK 构建；不把最低系统版本设置为 iOS 26。

## 0. 当前状态

Phase 1 和 Phase 2 已完成，不再作为后续待办：

1. 认证安全地基已完成：邮箱格式校验、邮箱验证码、Resend 发信、登录/注册限流、HTTPS、`COOKIE_SECURE=true`、生产 CORS 收敛。
2. 用户数据隔离已完成：session 保存 `userId`，本地任务/统计/同步缓存按 `taskflow:<userId>:...` 命名空间隔离，旧全局缓存会迁移到当前用户命名空间，登出会清除当前用户本地缓存。
3. Phase 3 的基础数据可信度已完成：任务写接口字段校验、普通任务列表排除软删除、账号删除后旧 access token 会立即失效。
4. Phase 3A 已完成：最近删除列表、恢复、永久删除、普通删除软删除化、前端最近删除入口。
5. Phase 3B 已完成：用户管理字段、后端数据导出接口、删除账号接口、账号页删除账号入口；前端 `Export Data` 入口已移除，后端导出接口作为隐藏合规/排查能力保留。
6. Phase 3C 已完成：任务新增服务端 `completedAt`，任务完成时由后端写入，`/user/stats` 基于服务端完成记录重算 `todayCount` 和 `streak`，同一任务重复完成不会重复计数。
7. Phase 4 已完成：任务同步加入持久 `operationId`、后端 `TaskOperation` 幂等记录、`lastKnownUpdatedAt` 版本冲突检测、`409 TASK_CONFLICT` 响应、前端冲突状态提示、账号页最近同步时间和待同步数量。
8. Phase 5 已完成：错误文案本地化、任务表单字段级校验、DDL 必填、估时可为空并显示 `--m`、密码规则提示、账号页分组、邮箱验证状态、通知权限状态、重新同步入口、隐私政策入口、空状态细分、删除恢复提示、同步状态说明、本地系统提醒通知。
9. Phase 6 已完成：任务表单弹窗保留移动端安全宽度，预估时长聚焦边框改为内侧显示；新增 `repeatUntilDate`，贯通后端 schema、migration、API、前端类型、本地缓存和同步 payload；重复任务改为创建时一次性生成到重复截止日期，并移除完成任务时滚动生成下一次的旧逻辑。

## 总体验收测试清单

1. 数据生命周期测试：删除、最近删除、恢复、永久删除、软删除过期策略。
2. 账号管理测试：删除账号、删除后 token 失效、重新注册；后端隐藏导出接口仅作排查/合规验证。
3. 统计可信度测试：重复完成、多设备完成、跨天 streak。
4. 同步测试：离线创建/编辑/完成/删除后重启，再联网同步；多设备冲突处理。
5. UI/UX 测试：中英文、键盘打开、错误提示、验证码流程、账号页、空状态、最近删除、排序拖拽、重复任务生成预览、日历搜索筛选、toast 和弹层遮挡。
6. 发布测试：生产 HTTPS、真实设备、隐私政策、审核账号、截图、后端 migration、`npm run check`。

## 默认假设

1. 保留“账号必需，支持跨设备同步”的产品定位。
2. App Store v1 不加入团队协作、公开分享、社交功能和广告追踪。
3. 离线可读写继续保留，但必须绑定最近验证过的 `userId`，不能跨用户复用缓存。
4. 生产邮件发送使用 Resend，发件邮箱使用已验证域名下的 `verify@mail.taskflow.top` 或等价地址。
